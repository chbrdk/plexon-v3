## Distinction

| Term | Meaning |
|------|---------|
| **Forbidden “wireframe”** | Thin gray end-state (empty X-boxes, no type/media mass) — Vision/craft-thin |
| **User wireframe / Bioframe / Skizze** | Layout **contract** — section order, CTA placement, char limits, image slots |

## Company-profile sketch (example)

Top → bottom:

1. **COMPANY PROFILE** header bar (simple — not a full product mega-nav unless drawn)
2. **Headline** (max **40** chars incl. spaces) + **Learn More** CTA + **large hero image below** (dashboard photo)
3. **Happy Customer** + sub (max **135** chars) + **4** icon cells + **MORE**
4. Mid **dashboard image** + button under it
5. Catchy contact title + **input | contact us** row + 3 footer icon squares

## Agent rule

When a sketch is attached or described: **follow the sketch structure first**; Default Overlay Hero only when no sketch. Ship finished craft (Hex, Fallgefühl, real media), not paper boxes.

# Exyte SEO/GEO Discovery (DE + EN)

Bilingual fillable PDF: **brief coverage (CHECKION, PLEXON, AUDION, Scrunch)** + **20 open questions**.

| File | `Exyte-SEO-Discovery-Form.pdf` |

## Structure

| Section | DE | EN |
|---------|----|----|
| A | Brief-Abdeckung MSQDX/Sitecore | Brief coverage |
| B | 20 offene Fragen | 20 open questions |

Each row/question: German + English labels, **one shared input field**.

## Generate

```bash
npm run generate:exyte-discovery-pdf
```

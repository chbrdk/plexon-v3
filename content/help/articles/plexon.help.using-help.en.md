# How Docs & Help work in the suite

The suite ships three help layers that share one content corpus:

1. **Micro** — `InfoTip` on jargon and metrics.
2. **Meso** — Docs (`/docs` public) and Help (`/help` when signed in), plus the Help Hub overlay (header `?`).
3. **Macro** — Platform Assistant chat for open questions.

## Find an answer

- On any screen, open Help (`?`) to see articles for *this* screen first.
- Browse or search the full index on `/help` (signed in) or `/docs` (public articles only).
- Still stuck? Use **Ask Assistant** — it can open the same article id.

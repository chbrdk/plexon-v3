# Guideline aktivieren

Eine **Guideline** ist das Markenregelwerk (Tokens + Compliance) in BRANDION für eine Collection. **Active** bedeutet: Dieses Pack liest CREATION über `active-pack`, und Measured evaluate misst dagegen.

Aktiviere eine Guideline, **stuft** andere Guidelines derselben Collection zurück.

## Schritte

1. BRANDION öffnen → Rail **Guidelines**.
2. Optional auf Collection / Project filtern.
3. Bestehende Karte öffnen **oder** **New guideline** → Name → Create (Studio öffnet).
4. Status prüfen: **Draft** / **Active** / **Archived**.
5. **Activate** wählen (oder Status im Dialog auf Active setzen).
6. Bestätigen: Status **Active**; eine andere Guideline derselben Collection ist nicht mehr Active.
7. Optional Design Tokens kurz ansehen — tiefes Editieren ist ein späterer Workflow.
8. Weiter zu **Analysis** für einen Measured-evaluate-Lauf.

## Regeln

- Für öffentliche Hilfe eine eigene Demo-Guideline bevorzugen — keine Production-Deposits ohne Freigabe.
- Nicht mit **Archived** als Erfolg enden.
- Fehlt Activate oder ist disabled: Rechte prüfen oder ob bereits Active.

# BRANDION: first two checks

BRANDION holds the **brand pack** for a Collection: Guidelines (tokens + rules) and **Measured evaluate** (compare a PDF or image against that pack).

There is no second “Brandion project”. Guidelines and evaluate runs bind to the same PLEXON **Collection**. The old Detection Lab name is gone — use **Analysis → Measured evaluate** (`/analysis`).

## Recommended order

1. **Activate a Guideline** — exactly one Active guideline per Collection is the pack truth for evaluate and for CREATION `active-pack`.
2. **Measured evaluate** — upload a controlled demo PDF/image, run evaluate, read Passed / Failed / Skipped and Findings.

If no guideline exists yet, create or open one before evaluating.

## Rules

- Prefer demo fixtures over customer files without permission.
- Failed findings are rule deviations — not “the brand is broken”.
- Do not film Detection Lab as a separate hub (redirect only).
- Mention CREATION consume only; do not claim tokens were pulled unless you show CREATION.

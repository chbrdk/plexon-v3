# Activate a Guideline

A **Guideline** is the brand rule set (tokens + compliance) in BRANDION for a Collection. **Active** means this guideline is the pack CREATION reads via `active-pack` and Measured evaluate measures against.

Activating one guideline **demotes** other guidelines on the same Collection.

## Steps

1. Open BRANDION → Rail **Guidelines**.
2. Optionally filter to your Collection / project.
3. Open an existing card **or** **New guideline** → name → Create (Studio opens).
4. Check status: **Draft** / **Active** / **Archived**.
5. Choose **Activate** (or set status to Active in the dialog).
6. Confirm status is **Active** and that another guideline on the same Collection is no longer Active.
7. Optionally skim Design Tokens — deep editing is a later workflow.
8. Continue to **Analysis** for a Measured evaluate run.

## Rules

- Prefer a dedicated demo guideline for public help — not production deposits without clearance.
- Do not end on **Archived** as success.
- If Activate is missing or disabled, check permissions or whether it is already Active.

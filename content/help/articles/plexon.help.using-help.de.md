# So funktionieren Docs & Hilfe in der Suite

Die Suite liefert drei Hilfe-Schichten mit demselben Content-Corpus:

1. **Micro** — `InfoTip` bei Jargon und Metriken.
2. **Meso** — Docs (`/docs` öffentlich) und Hilfe (`/help` nach Login), plus Help-Hub-Overlay (Header `?`).
3. **Macro** — Platform-Assistant-Chat für offene Fragen.

## Antwort finden

- Auf jedem Screen Hilfe (`?`) öffnen — zuerst Artikel *zu diesem* Screen.
- Index durchsuchen unter `/help` (eingeloggt) oder `/docs` (nur öffentliche Artikel).
- Immer noch stecken? **Ask Assistant** — derselbe Artikel kann geöffnet werden.

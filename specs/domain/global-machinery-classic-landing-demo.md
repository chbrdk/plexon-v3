# Global machinery classic corporate demo

**Status:** Accepted — 2026-08-24  
**Artifact:** `public/kernwerk-classic.html`  
**Purpose:** Conventional, compact corporate alternative for fictional manufacturer KERNWERK.

## Goal

Show KERNWERK in a familiar corporate website structure with moderate
typography, a centered grid, compact spacing, clear navigation, and balanced
information density. The page should feel current and trustworthy without
becoming expressive, technical, or visually busy.

## Keep / reshape / drop

| Decision | Treatment |
|---|---|
| Keep | KERNWERK positioning, machinery families, lifecycle service, global presence, standalone HTML |
| Reshape | Use a conventional max-width content grid, two-column hero, three-column capability modules, standard case-study and news rows |
| Drop | Oversized typography, asymmetrical full-bleed bands, hover-revealed media, giant statements, experimental map and dramatic color fields |

## SPIRION synthesis

- Use a standard hero-to-feature rhythm with contained photography.
- Keep text and images in strict rectangles aligned to a centered grid.
- Use clear hierarchy, small utility navigation, restrained borders, and
  shallow shadows only where useful.
- Keep primary actions conventional and consistently styled.
- Do not copy source brands, copy, imagery, or exact layouts.

## Page arc

1. Utility bar and primary navigation
2. Two-column corporate hero
3. Proof strip
4. Capabilities grid
5. Company and lifecycle section
6. Reference project
7. Global service and news
8. Contact band and structured footer

## Acceptance

1. One self-contained HTML file with inline CSS and no external asset host.
2. Content stays inside a conventional centered grid.
3. Spacing is compact but readable; no section feels crowded or empty.
4. The page is responsive, keyboard accessible, and honors reduced motion.
5. The canonical public route, focused tests, and production build pass.

# Global machinery landing demo

**Status:** Accepted — 2026-08-24  
**Artifact:** `public/kernwerk.html`  
**Purpose:** Standalone HTML concept for a fictional global machinery manufacturer.

## Goal

Present KERNWERK as an established, internationally capable industrial partner
that feels contemporary and human without looking nostalgic, cybernetic, or
like enterprise software.

## Keep / reshape / drop

| Decision | Treatment |
|---|---|
| Keep | Semantic standalone HTML, responsive CSS, labelled placeholder imagery, accessible navigation |
| Reshape | Machinery is presented with gallery-like clarity; global scale is told through people, lifecycle, and local service rather than dashboards |
| Drop | Corporate-blue templates, neon technology effects, glass panels, blueprint overload, generic icon-card grids, invented performance claims |

## SPIRION synthesis

- Isolate machinery against quiet fields and use large background typography as
  a spatial frame rather than decoration.
- Combine small utility chrome with generous display type and strict alignment.
- Use warm off-white, charcoal, oxidized red, muted green, and honest material
  textures expressed through labelled CSS placeholders.
- Sequence the page from a media-led promise to systems, lifecycle partnership,
  human case story, global presence, and contact.
- Do not copy source brands, copy, imagery, or exact layouts.

## Page arc

1. Global brand promise / hero
2. What customers can rely on
3. Machinery families
4. Lifecycle partnership
5. Human case story
6. Global service presence
7. Contact and footer

## Acceptance

1. One self-contained HTML file with inline CSS and no external asset host.
2. The first viewport reads as industrial, confident, and human.
3. Placeholder media is clearly labelled and visually differentiated.
4. The page is responsive, keyboard accessible, and honors reduced motion.
5. The canonical public route, focused tests, and production build pass.

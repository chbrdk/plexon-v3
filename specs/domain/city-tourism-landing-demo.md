# City tourism landing demo

**Status:** Accepted — 2026-08-24  
**Artifact:** `public/lindenau.html`  
**Purpose:** Standalone HTML concept for a contemporary city-tourism experience.

## Goal

Create a reusable tourism landing-page concept for the fictional German city
Lindenau. The experience should feel current and editorial while expressing
warmth, craft, hospitality, and living tradition.

## Keep / reshape / drop

| Decision | Treatment |
|---|---|
| Keep | Standalone semantic HTML, responsive CSS, keyboard access, reduced-motion support |
| Reshape | Familiar tourism content becomes an editorial journey: cinematic arrival, curated themes, events, itinerary, planning CTA |
| Drop | Generic destination card kits, cold corporate blue, glass panels, app-dashboard chrome, unverifiable visitor claims |

## SPIRION synthesis

- Open with an immersive media-first hero and let large editorial type sit on
  and beside image placeholders.
- Pair oversized serif display text with small, functional sans-serif chrome.
- Use warm natural tones, strict image crops, generous whitespace, and
  asymmetric split layouts.
- Keep conversion visible through outlined planning actions without turning the
  page into a booking portal.
- Do not copy source brands, copy, imagery, or exact layouts.

## Page arc

1. Arrival / hero
2. City promise
3. Curated experiences
4. Seasonal events
5. Living tradition
6. 48-hour itinerary
7. Planning CTA and footer

## Acceptance

1. The deliverable is one self-contained HTML file with inline CSS.
2. Placeholder media is clearly labelled and requires no external asset host.
3. The page is responsive from mobile to wide desktop.
4. Headings, landmarks, links, focus states, and reduced motion are accessible.
5. The page renders successfully through the existing local preview server.
